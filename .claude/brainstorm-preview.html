Proposal 1

Animation Polish

The visual spec calls for breathing, blinking, ambient glow, and sparkle reactions — only the float animation is currently implemented. These three additions would make the companion feel truly alive.

Ambient Glow Halo

Soft radial glow pulsing behind the character. Changes color per mood. Already in the spec, not yet in code.

Pet Sparkle Burst

CSS particle burst on every pat — small petal-colored dots rise and fade. Makes the interaction feel tactile.

Character Blink

Occasional blink overlay (every ~5–7 s) using a CSS pseudo-element. Adds life without Live2D or image swapping.

Summary

What We'd Build

All three proposals are CSS/React-only — no new dependencies, no architecture changes. Pure polish.

Implementation scope

1
Animation polish — Add ambient glow halo (`@keyframes haloBreath`), CSS blink overlay (pseudo-element), EXP bar glow animation, and pet sparkle burst (absolutely-positioned particles triggered on click). ~40 lines of CSS + 1 small React state change for sparkles.
2
Panel companion status card — Replace the static hero card in `PanelView.tsx` with a live `CompanionStatusCard` component that reads `funState`, `mood`, and `companionActivities` already available in the panel. No new IPC needed.
3
Mood glow system — Extend the existing `companion-card-{mood}` CSS class pattern to add card-level box-shadow and halo color per mood. ~25 lines of CSS. Covers all 6 moods consistently.
