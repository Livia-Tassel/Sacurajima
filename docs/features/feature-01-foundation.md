# Feature 01: 项目脚手架与规范基线

## 目标

建立 Sakurajima 的基础工程、文档体系和开发规范，确保后续所有开发都能沿着统一的结构推进。

## 设计

- 使用 Electron + Vite + React + TypeScript
- 建立 `main / preload / renderer / shared` 分层
- 引入测试、打包和类型检查基础设施
- 建立文档索引、功能文档和审查记录位置

## 验收标准

- 仓库可安装依赖并启动基础开发环境
- 文档骨架完整
- 存在统一脚本用于开发、构建、测试
