# Feature 07: 交互陪伴内核

## 目标

将现有“聊天 + 桌宠外观”升级为具备主动互动能力的桌面陪伴系统，提供可控、低负担且可持续的情绪关怀体验。

## 核心行为

- 桌宠可在关键时机主动发起关怀
- 用户可在桌宠侧通过快捷动作快速回应
- 面板可查看近期陪伴动态，并一键注入聊天草稿
- 主动行为支持开关、强度控制、静默时段和冷却限制

## 实现约束

- 仅保留文本交互，不引入语音、TTS、Live2D
- 主动互动仅在应用运行期间触发，不依赖系统通知
- 所有偏好和轻量互动记忆仅保存在本地 JSON
- 同一提示模板 24 小时内不重复
- 默认静默时段为 `23:00-08:00`（本地时区）

## 实现结果

- 已新增主进程 `CompanionEngine`，统一处理状态机、定时触发、静默时段和冷却逻辑
- 已新增陪伴状态持久化存储，保存偏好配置和轻量互动记忆
- 已新增共享陪伴类型与事件合同，并通过 preload 暴露 `companion.*` API
- 已新增 companion 侧主动关怀卡片和快捷回应动作
- 已新增 panel 顶部“陪伴动态”区域，可一键注入聊天草稿但不自动发送
- 已将聊天事件与陪伴状态联动，形成双向反馈闭环

## 验证结果

- `npm run typecheck`：通过
- `npm test`：通过
- `npm run build`：通过

## 验收标准

- 冷启动后可触发首次主动关怀
- 用户可在 companion 侧完成一次“提示 -> 回应 -> 反馈”闭环
- 关闭主动陪伴后，聊天主流程仍可正常使用

## 安全与严谨性审查

- 新增 IPC 仅暴露白名单动作，不提供任意写入能力
- 主动策略在主进程执行，避免 renderer 绕过限频规则
- 互动记忆仅保存行为摘要，不保存额外敏感信息
- 静默时段和去重规则默认开启，降低打扰风险
