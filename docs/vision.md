# Sakurajima 产品愿景

## 目标

Sakurajima 是一个可本地运行、开箱即用的陪伴桌面系统。用户在本机安装应用后，只需配置兼容 OpenAI 的 API 信息，即可获得一个驻留桌面的可爱陪伴角色和对应的聊天能力。

## v1 用户价值

- 提供随时可见、低打扰的桌面陪伴体验
- 通过简单配置接入 New API 或其他 OpenAI-compatible 服务
- 用统一、可爱的视觉系统传递“樱花陪伴感”
- 所有数据默认本地保存，优先保护用户隐私

## 体验原则

- 降低上手门槛：首次启动即引导配置，避免暴露多余概念
- 降低打扰感：桌宠默认轻量动效，允许随时隐藏
- 降低风险面：渲染层无高权限能力，敏感信息加密存储
- 降低不一致：任何功能先出文档，再出代码

## v1 边界

- 首发仅支持 macOS ARM64
- 交互以文字为主
- 不包含语音输入、TTS、Live2D、云同步、复杂长期记忆
- 图片资源在开发阶段生成并内置，不依赖运行时图像能力
