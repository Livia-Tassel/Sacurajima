# UI 规范

## 全局原则

- 可爱但不幼稚
- 信息层级清晰，避免拥挤
- 任何错误都要有明确下一步动作

## 首次启动

- 无有效配置时直接显示引导页
- 引导页默认选择 `New API`
- 必填项：站点地址、API Key、模型名
- 支持“测试连接”和“保存并开始”

## CompanionWindow

- 默认展示角色立绘与当前状态文案
- 支持拖动位置
- 点击角色打开 `PanelWindow`
- 右键可呼出简化菜单

## PanelWindow

- 左侧为会话列表
- 右侧为聊天主区域
- 顶部提供设置入口和连接状态
- 底部输入框提供发送、中止生成能力

## 空态与错误态

- 无会话：展示欢迎文案与快速开始提示
- 配置缺失：展示引导卡片，不允许发送消息
- 网络错误：展示重试按钮与错误摘要
- 鉴权失败：提示用户检查 API Key 和站点地址
