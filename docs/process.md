# 开发流程

## 规则

1. 先写或更新文档，再写代码
2. 任何接口与数据结构变更必须同步更正文档
3. 每个功能结束前必须完成测试、审查、一致性检查
4. 每个功能完成后单独提交 Git commit

## Definition of Done

- 功能文档已存在且已更新
- 相关通用文档已同步
- 代码实现完成
- 测试已运行，或未运行原因已记录
- 安全与严谨性审查已记录
- 工作区无未解释的偏差

## 提交流程

1. 确认文档状态
2. 实现代码
3. 运行检查
4. 记录审查结论
5. 提交功能级 commit

## 文档优先级

- 文档与代码冲突时，优先修正为一致状态
- 若文档错误导致实现偏差，必须在同一功能周期内修正文档与代码
