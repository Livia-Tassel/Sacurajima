# Sakurajima

Sakurajima 是一个本地运行的可爱陪伴桌面系统。v1 以 macOS 为首发平台，采用 Electron + React + TypeScript，提供悬浮桌宠、聊天面板、New API 优先兼容配置，以及文档驱动的开发流程。

## 开发原则

- 文档优先，代码服从文档
- 功能级提交，不混合变更
- 每个功能完成后做安全、严谨性、一致性审查
- 本地优先，敏感信息最小暴露

详细规范见 [docs/process.md](docs/process.md)。

## 常用命令

- `npm install`
- `npm run dev`
- `npm test`
- `npm run build`
- `npm run make`

用户上手和排障见 [docs/quickstart.md](docs/quickstart.md) 与 [docs/troubleshooting.md](docs/troubleshooting.md)。
